# CourseBench 数据源与指标参考指南

## 1. 接口与服务节点

CourseBench 提供了开放的 REST API 接口，当前支持以下服务器节点（带有自动主备切换机制）：
- 主节点 / 镜像节点: `https://coursebench.zambar.dev`
- 官方主域名: `https://coursebench.org` (可能进入维护状态)

### 常用端点
- `GET /v1/course/all`: 获取全校所有课程基本元数据（包括 id、name、code、institute、credit、score、comment_num）。
- `GET /v1/course/{id}`: 获取单门课程的开课大纲、教学班分组 (groups) 以及教师信息 (teachers)。
- `GET /v1/comment/course/{id}`: 获取该课程下历届同学提交的所有评价列表（包括标题、正文内容、学期 semester、四维评分、点赞数、用户信息等）。
- `GET /v1/teacher/all`: 获取全校教师名录与所属单位信息。

## 2. 四维评分标准体系

CourseBench 评价系统的各项得分均为 **5.0 满分制**：

1. **综合质量 (score[0])**：
   - 衡量课程内容的充实度、讲授逻辑、学生收获。
   - 4.5+ 为广受赞誉的优质课程。

2. **平时作业与工作量 (score[1])**：
   - 衡量日常课业负荷、作业量、实验及 Pre 负担。
   - **特别机制**：分数越**高**代表日常**越轻松、负担越小**；分数越**低**（如 1.0~2.5）代表**工作量极大、硬核硬课**（如编译原理、体系结构设计、高负荷实验课等）。

3. **考核难度 (score[2])**：
   - 衡量期中/期末考试、大作业或项目考核的友好程度。
   - 分数越**高**代表考核越友好（题目紧扣课件、开卷、题量适中）；分数越**低**代表考核严苛有挑战。

4. **给分情况 (score[3])**：
   - 衡量最终总评与成绩曲线的宽容度。
   - 4.5+ 代表给分优秀率高、不压分、老师乐于向上捞人；低于 3.5 代表给分较为严格。

## 3. 上海科技大学学期编码规则

在 CourseBench 评论中，`semester` 字段采用 6 位数字编码：
- 前 4 位代表学年起始年份，后 2 位代表学期类型：
  - `01` = **秋季学期** (Fall Semester, 9月 - 次年1月)
  - `02` = **春季学期** (Spring Semester, 2月 - 6月)
  - `03` = **夏季学期** (Summer Semester, 7月 - 8月)
- 示例：
  - `202401`: 2024-2025 学年秋季学期
  - `202502`: 2024-2025 学年春季学期

## 4. 学院分类与专业代号

- **信息科学与技术学院 (SIST)**: 计算机科学与技术 (CS)、电子信息工程 (EE)
- **物质科学与技术学院 (SPST)**: 物理学 (PHYS)、化学 (CHEM)、材料科学与工程 (MSE)
- **生命科学与技术学院 (SLST)**: 生物科学 (BIO)、生物技术 (BT)
- **生物医学工程学院 (BME)**: 生物医学工程
- **创业与管理学院 (SEM)**: 经济学 (ECON)、金融学 (FINA)、管理学 (MGMT)、创新创业 (ENT)
- **创意与艺术学院 (SCA)**: 工业设计、互动媒体、影视后期、数据可视化 (ARTS)
- **数学科学研究所 (IMS)**: 数学与应用数学 (MATH)
- **人文科学研究院 / 书院**: 通识人文 (GEHA)、体育 (GEPE)、思想政治 (SMRT)、书院通识 (GE)
